Accordion

A vertically stacked set of interactive headings that each reveal a section of content. Built on native <details> and <summary>, so it is keyboard accessible, animates smoothly where the platform supports it, and still works with JavaScript off.

Basic

Accordions are exclusive by default: opening one item closes the others, and only the first item starts open. The markup is plain <details> elements inside a data-accordion group, with data-accordion-item on each pair.

Disabled

					

						Mark an item with data-disabled to lock it closed. The trigger
						is dimmed and unclickable, and the JavaScript layer re-closes it even if
						the browser opens it via keyboard.

Bordered

						dividers between items. To drop the container entirely, stack standalone
						details elements with class="accordion" instead
						of wrapping them in a group.

API reference

					

						
							

								Attribute
								Where
								Description
							

						
						
							

								data-accordion
								Container
								Groups items into a bordered, exclusive accordion.
							

							

								data-accordion-multiple
								Container
								Allows several items to stay open at once.
							

							

								data-accordion-item
								<details>
								Marks a heading/content pair as an accordion item.
							

							

								data-disabled
								Item
								Locks the item closed: dimmed, unclickable, re-closed even via keyboard.
							

							

								open
								Item
								Native attribute. The item starts open; exclusive groups keep only the first.
							

							

								class="accordion"
								<details>
								Standalone item outside a group, with no container border.
							

						
					

					

						Styling comes from the --border, --radius-lg,
						--card, --muted and --ring tokens,
						so the look follows your theme automatically. The open/close animation
						uses the platform details transition where supported
						(Chrome 131+ and other engines that understand
						::details-content) and degrades gracefully everywhere else.
