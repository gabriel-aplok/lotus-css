Alert

Displays a callout for user attention. Icon, title, description and an optional action slot together inside one bordered box, with variants driven by the theme tokens.

  • Basic
  • Destructive
  • Action
  • Custom colors
  • API reference

Basic

An alert is a .alert box with an icon, a .alert-title and a .alert-description. The icon is either a .alert-icon element or the first svg child.

Custom colors

					

						Every alert reads its colors from three variables:
						--alert-bg, --alert-fg and
						--alert-border. Override them on the element for a
						custom scheme. The built-in variants are just variable assignments,
						and color-mix() keeps hand-picked colors theme-aware.

API reference

					

						
							

								Class
								Where
								Description
							

						
						
							

								.alert
								Container
								The callout box. Defaults to the secondary palette.
							

							

								.alert-icon
								Icon
								Icon slot. A leading svg child is styled the same way.
							

							

								.alert-title
								Title
								Bold heading for the alert.
							

							

								.alert-description
								Body
								Supporting copy. .alert-body is an alias.
							

							

								.alert-action
								Action
								Action slot, pushed to the top-right corner.
							

							

								.primary · .success · .warning · .destructive · .accent
								Variant
								Re-points the alert colors to the matching token.
							

							

								.is-full
								Utility
								Forces the alert to fill its container width.
