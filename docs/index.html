LOTUS.css

Classless CSS with a neutral, oklch token system. Automatic dark mode. An optional 9 kB JS layer for dialogs, toasts, tabs and more. Semantic HTML still looks like something.

Get started Browse the demo GitHub ↗

Features

Semantic HTML alone covers a lot. The JavaScript layer covers the bits that need a browser.

⚡

Lightweight

~52 kB of CSS minified, and the optional JS layer is under 9 kB. No build step required.

🧱

Classless by default

Style semantic HTML out of the box. Add classes only when you need them.

🎨

Design tokens

An oklch palette in the spirit of Vercel / shadcn. Every color is a CSS variable you can override.

🌙

Automatic dark mode

Follows prefers-color-scheme. Override with .dark/.light, or a toggle button.

🧩

Component library

Navs, tabs, cards, dialogs, sheets, toasts, tooltips, carousels, accordions, badges, spinners, and so on.

🪄

Progressive interactivity

Scroll reveals, page transitions and code copy buttons. Nothing breaks if JavaScript is off.

Customize

					
Every color, radius, shadow and font is a design token. Override any of them in your own CSS.
