Toasts

Toasts stack in the bottom-right corner and dismiss themselves after 4 seconds.

Programmatic API
import { toast } from 'lotus-css/js';

toast('Saved', { type: 'success', title: 'Done' });

Tooltips

Pure CSS — no JavaScript required. Tooltips also appear on keyboard focus.

Markup

Accordions

What is LOTUS.css?

Classless CSS with neutral design tokens and an optional JS layer.

Does it need a build step?

No — link the stylesheet and go. The JS layer is optional and dependency-free.

Is dark mode automatic?

Yes, via prefers-color-scheme, with manual .dark/.light overrides.

Markup
<div data-accordion>
  <details data-accordion-item open>
    <summary>Question</summary>
    <p>Answer…</p>
  </details>
</div>
